# Skyline Travels Website

A complete responsive HTML/CSS/JavaScript travel agency website inspired by the information architecture of the supplied Sky Bridge Travel & Tourism reference.

## Files
- index.html — complete page structure/content
- style.css — responsive styling
- script.js — mobile menu, package filtering/search, testimonial slider, booking form interaction

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Customize
Search and replace:
- SKYLINE / SKYLINE TRAVEL & TOURISM
- phone/email/address
- package names and prices
- destination names
- Unsplash image URLs

The booking form is front-end only. Connect it to your backend, Formspree, Web3Forms, email service, or CRM before production.

## Note
Images currently use remote Unsplash URLs so the demo works without a local image folder.

## Logo
The supplied Skybridge Travel & Tourism logo is included at `assets/skybridge-logo.png` and is used in the header and footer.
